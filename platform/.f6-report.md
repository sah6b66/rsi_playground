## Concerns / 留观

1. **B-1 smoke 语义**：P0 的 `_smoke_run` 用 FakeCarrier 类 carrier 的 parse_error TaskResult 做基线/overlay 等价比较；S11 真实执行器接入后应升级为真实双跑。bootstrap 接线后生产 run_batch 会真实注入（离线 smoke 双跑失败→自动降级原目录，行为安全）。
2. **B-3**：ParallelBatchRunner 尚无 API/CLI 入口调用（本次只交付执行器与消费语义，入口属 F8/API 层切片）。
3. **B-6**：等价性 diff 仅在池会话路径生效；backend 纯路径（无 pool）保留原行为（设计允许，S11 真后端均带 pool）。`normalize_config` 的提示符前缀（`<`/`!`/`#`/`%`/`*`）为 P0 启发式。
4. **B-5**：verify_image 仅实现 docker inspect 一项（DD 四项检查的 P0 子集）；--version/ls /trace/plugin list 留 S11。多主机时默认探 "main"。
5. **B-11**：deploy/vendor 不在 platform git 仓库内，代理重写需在 deploy 侧单独提交/分发。
6. `labs.status` 用表约束允许的 `'ready'`（任务文本中的 'active' 不满足 CK 约束）。
